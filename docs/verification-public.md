# v0.3.0の検証範囲

## 確認済み

- Mac Apple Siliconでの起動、コメント描画、PowerPoint全画面上のテストコメント表示。
- スマートフォン2台からの投稿、ロック解除後の投稿。
- QR表示中とタブ収納中のコメント継続、QRの移動・サイズ変更、配置保存、タブからの復帰。
- 基本・言語自動試験16件とElectron接続試験16項目の合格。
- 50参加者のWebSocket接続と、50投稿の配信順序を確認する自動試験。

## 未確認・制約

- Windows、Intel Mac、複数ディスプレイでの実機動作。
- 40台のスマートフォンによる3時間の連続利用。
- 会場のPC、プロジェクター、回線を組み合わせた動作。
- OS署名、公証、組織の端末管理環境での配布。
- 通信断中に失われたコメントの復元。コメント本文は永続保存しません。

Cloudflare Quick Tunnelは試験用で、稼働保証はありません。
公開HTTPS経由の投稿には成功例がありますが、回線による名前解決や到達性の失敗も発生しています。
無料接続での長時間の安定性を保証するリリースではありません。

セッションの有効期間は12時間です。
内蔵サーバーを使う場合、アプリの終了でセッションと参加URLが利用できなくなります。
再起動後は新しいセッションとQRを作成してください。

## v0.3.0の追加確認

日本語／英語の言語選択、英語画面からの投稿、入力エラーの英語表示、言語切替時の下書き保持、再読込後の選択保持を自動試験で確認しました。
言語切替で、参加者のコメント本文やセッション名は翻訳しません。
